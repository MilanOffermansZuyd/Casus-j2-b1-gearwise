
# GearWise - Casus J2 B1

## Over dit project
GearWise is een applicatie ontwikkeld als onderdeel van de casus voor **Jaar 2, Blok 1**. Het doel is om een platform te bieden voor het beheren en bekijken van Avdertenties (zoals auto-onderdelen) op een gebruiksvriendelijke manier.

## Functionaliteiten
- **Advertentieoverzicht**: Bekijk een lijst van Advertenties.
- **AdvertentiesDetails**: Klik op een Advertentie om meer informatie te zien.
- **Wikipedia**: Klik onder een Advertentie op bekijk en zie een wiki over het Product.
- **Responsive design**: Geschikt voor verschillende schermformaten.

## Technologieën
- **C# (.NET)** voor de backend
- **ASP.NET MVC** voor de webapplicatie
- **Entity Framework** voor database interactie
- **SQL Server** als database

## Structuur
- `Controllers/` – Bevat de logica voor het verwerken van requests.
- `Models/` – Definieert de data-structuren.
- `Views/` – HTML/CSS voor de gebruikersinterface.
- `wwwroot/` – Statische bestanden zoals CSS en JS.
